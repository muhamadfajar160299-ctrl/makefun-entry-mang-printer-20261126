One line, in the office printer's own voice, as its comeback to the paper
jams, the cryptic error codes, and the thumps when it stops working.

## The line

> I jammed on page 47 of 48. Not an error. A decision. You thumped me
> twice, so I'm keeping the last page.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

`main.py` writes `entry.txt` (104 characters) to the directory named by
`MAKEFUN_OUTPUT_DIR` only — never next to the script, so it runs cleanly
in the grader's read-only sandbox.
